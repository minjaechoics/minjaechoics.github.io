# minjaechoics.github.io

MinJae Choi's personal website — built on the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

- **About / CV / Projects / Blog / News / Archive** are generated by Jekyll from `_pages/`, `_data/cv.yml`, `_projects/`, `_posts/`, and `_news/`.
- `wiki.html` (+ `wikicontent/`) is kept as a standalone static page — a small client-side markdown viewer for KAIST course notes, linked from the about page.
- See [docs/CUSTOMIZE.md](docs/CUSTOMIZE.md) and [docs/INSTALL.md](docs/INSTALL.md) for how the theme itself works.

Deployed automatically to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.
