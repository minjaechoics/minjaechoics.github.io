# minjaechoics.github.io

MinJae Choi's personal website — built on the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

- **About / CV / Projects / Blog / News** are generated by Jekyll from `_pages/`, `_data/cv.yml`, `_projects/`, `_posts/`, and `_news/`.
- A few standalone pages are kept as plain static HTML and linked from the "more" nav dropdown: `archive.html` (KAIST coursework), `design.html` (design portfolio), `amplify.html` (Imagine Cup project), `wiki.html` (course-notes wiki), and `falcon.html` (a small competition-tracking dashboard).
- See [docs/CUSTOMIZE.md](docs/CUSTOMIZE.md) and [docs/INSTALL.md](docs/INSTALL.md) for how the theme itself works.

Deployed automatically to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.
